# Nikhil Singh — Portfolio Website

## Run locally
1. Extract the ZIP.
2. Open `index.html` in any modern browser. (Recommended: VS Code + Live Server.)
3. Update sample project cards, email address, and social profile links in `index.html`.

## Files
- `index.html`: page structure and content
- `style.css`: responsive styling
- `script.js`: mobile menu and dynamic footer year

## Sections
Home/Hero, About, Skills, My Work, Contact, Footer.

## Tech stack
HTML5, CSS3, JavaScript (vanilla).

- `profile.jpg`: cropped profile photo used in the hero section.
